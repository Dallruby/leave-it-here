# Leave It Here 상담센터

공개 사이트: https://dallruby.github.io/leave-it-here/

HTML, 이미지, 오디오, 글꼴로 구성된 정적 사이트입니다.
GitHub Pages는 `main` 브랜치의 `/ (root)` 폴더를 게시합니다.

- `index.html`: 화면, 문구, 메뉴, 팟캐스트 플레이어
- `assets/`: 표정 이미지, 마이크, 타이틀, 오디오, 글꼴
- `.nojekyll`: Jekyll 처리 생략

상담실 연결 주소: https://share.crack.wrtn.ai/iuj74o

글꼴 `pretendard-subset.woff2`는 일부 글자만 담고 있습니다.
문구에 새 글자를 추가하면 해당 글자가 다른 글꼴로 보일 수 있으므로,
문구 변경 시 글꼴 포함 여부도 확인해주세요.
